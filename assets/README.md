# Assets - Kong Games Linktree

Esta pasta é destinada para armazenar os assets visuais do linktree.

## Arquivos necessários

### Logo Principal
- **Nome do arquivo:** `logo.png`
- **Descrição:** Logo da Kong Games que aparecerá no topo da página
- **Formato recomendado:** PNG com fundo transparente
- **Dimensões recomendadas:** 512x512px ou maior (quadrado)
- **Observação:** A imagem será exibida em um círculo de 128x128px

## Como adicionar o logo

1. Coloque seu arquivo de logo nesta pasta
2. Renomeie o arquivo para `logo.png`
3. A página irá carregar automaticamente o logo

## Outros elementos

Você pode adicionar outros elementos visuais nesta pasta conforme necessário, como:
- Ícones personalizados
- Imagens de background
- Banners promocionais

## Fallback

Se o logo não for encontrado, a página exibirá automaticamente um ícone de gamepad como substituto.
